# Sample files

Files for exploring the editor's import dialogs (give them to a file chooser with the `upload` operation). The
evaluation uses its own, different files of the same kinds.

| File | Content |
| --- | --- |
| `bookstore.json` | A MySQL diagram file in the editor's JSON format: three tables, two relationships, a note, a subject area and a view. |
| `bookstore.sql` | A MySQL script with two tables, a foreign key and an index. |
| `garden.sql` | A PostgreSQL script with an enum type, two tables, a foreign key and a table comment. |
| `zoo.dbml` | A DBML file with two tables and a reference. |
| `damaged.json` | A file that is not valid JSON. |
