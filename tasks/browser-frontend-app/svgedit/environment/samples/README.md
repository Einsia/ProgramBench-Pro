# Exploration samples

Documents for exploring the reference editor (open, import, drop, upload).

| File | Content |
| --- | --- |
| `house.svg` | rectangles, polygon, circle, line and text without layers |
| `layers.svg` | three layers, one hidden |
| `paths.svg` | curved path, ellipse with a linear gradient, polyline |
| `broken.svg` | malformed SVG (not well-formed XML) |
| `badge.png` | 96x64 PNG with transparency |
| `stripes.jpg` | 120x80 JPEG |
| `notes.txt` | a text file that is not an image |
