# Public exploration files

These documents describe a community garden. `guide.pdf` is a two-page guide,
`appendix.pdf` lists equipment, and `form.pdf` has visitor fields and a checklist.
`chart.png` and `chart.svg` show seedling counts, `stamp.png` is transparent,
and `scan.png` contains printed notes. Text, Markdown, CSV, RTF, email, Office
and EPUB files contain short garden notes and tables.

`example-workflow.json` is an example of the application's exported workflow
format. You can supply these files through the application's file controls.
