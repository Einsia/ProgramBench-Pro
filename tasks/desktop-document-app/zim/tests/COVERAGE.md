# Reviewed Zim coverage

Version 1.0.0, reference Zim 0.77.2. Exact counts and budgets come from `data/manifest.json`: 57 episodes (43 GUI episodes and 14 program episodes), 123 frontend and 667 backend points. GUI episodes start on a fixture notebook that is uploaded into the notebook folder before the first goal; every GUI checkpoint has at least one frontend assertion judged by the evaluator agent, and the saved page files, page lists, notebook settings, export trees, the clipboard and the window titles are read back through the runtime and checked by program checks that the evaluator agent never sees. Program episodes run no evaluator agent: every scored row is one deterministic observation of the product command line or of the notebook files, compared with the frozen standard answer after projections that drop generated and unordered values (the generator version, absolute paths, creation dates, and the order of search results unless the run asks for an order). Runs whose observation repeats another row are unscored setup rows, and rows whose expected result is an error exit, an empty result or an unchanged file count together with a positive row of the same scenario.

| Coverage | Behavior |
| --- | --- |
| Search (command line) | Query syntax (words, OR, AND, NOT, brackets, quoted phrases, globs, leading plus), keywords (name, tag, links, linksto, content, the case operator), implicit and exact tags, Unicode page names, a bulk notebook of 60 pages (words, tags, sections, word and tag pairs, links), and an option notebook of six pages that are not in name order where whole words, case, scores, name order and score groups each change the result; error exits (empty query, missing notebook) |
| Export (command line) | html, markdown, rst and latex with every bundled template on the core notebook; single markup constructs (inline markup, heading levels, lists, checkboxes, verbatim, rules, every link kind, images, anchors, tags, Unicode, special characters) in four formats; the task and link notebooks in four formats; custom template files (page and loop variables, IF and ELSE, single file mode, one page, other formats, unknown names, broken syntax); single page, single file, index page, overwrite and refusals; error exits (no output location, missing page) |
| Import and convert (command line) | Wiki files (single, several, sub pages, name clashes, Unicode, headerless) and markdown files (headings, inline markup, lists, links, code blocks, quotes, rules, tables, Unicode); notebook conversion to markdown and back, the extension option and refusals |

Representative user goals stand in for every fixture x operation x save permutation; the large matrices of the command line are scored row by row on the program side.

Not scored, with the reason.
- Entry points that start other programs, load code, open manuals or other notebooks, or reach outside the exchange folders are refused by the runtime: Open Another Notebook, Send To, Print to Browser (also the Print button of the task list window), Templates, Open Attachments Folder, Open Notebook Folder, Open Document Root, View Debug Log, Start Web Server, Edit Source, Custom Tools, the Edit buttons of Insert Date and Time and Insert Symbol (they open a settings file in a text editor), the Browse button of the File Exists dialog (file manager), the Key bindings and Applications tabs of the preferences, the plugin folder and online links, the Help menu, and clicks on external links.
- Recent Changes follows file modification times, which use the real clock while the product clock is fixed.
- Close and Quit end the application; staying settings across a restart are scored through the restart checkpoint of the Table of Contents episode.
- Save A Copy, Copy Location, Cut, Copy, Paste and Delete of a selection, Cut Line and Reload have no visible effect in the window of their own (a frontend point would rest on an unchanged window); the clipboard and pasting are scored through Copy Line, file writing through the page and export checks.
- Check and Update Index has no visible result; every program scenario builds the index through the command line.
- Find Next and Find Previous need a page with several matches in view and repeat the find bar; Search Backlinks opens the same Search dialog with a links query, which the command line search scores.
- Insert Image, Attach File and the attachment browser need binary inputs or a sleeping thumbnail thread that fails under the fixed clock; image markup is scored through the markup export family.
- Move Selected Text, Remove Link and the table editor depend on a selection or caret placement inside an object that the evaluator can not see reliably in the accessibility tree.
- Plugins whose tools are not in the image (diagram, ditaa, equation, GNU R, gnuplot, mermaid, score, sequence diagram, link map, source view, spell checker), the command palette (it runs refused menu entries itself), the tray icon and screenshot insertion (platform), and the version control side by side compare.
- The remaining plugins without external tools (Arithmetic, BackLinks Pane, BookmarksBar, Distraction Free Editing, Indexed Full-Text Search, Inline Calculator, Journal, Line Sorter, Path Bar, Quick Note, Tags, Window Title Editor) are represented by Task List and Table of Contents, which use the same Plugins tab and persistence.
- Server mode and the plugin, manual and gui command line options.

Dependencies and companions. A checkpoint that builds on an earlier result declares it. Points that only confirm a refusal, an error exit, an empty result or an unchanged file count together with a positive companion in the same scenario.

reference/ contains the deterministic recipes for the pinned standard only. They drive the same runtime operations as the evaluator and are never the candidate's frontend contract.

## Interface and budgets

The surface is the task runtime's desktop (shared desktop module `blackbox_desktop.py`): a private 1280x900 Xvfb display, D-Bus and AT-SPI session per episode, run as the candidate user; one virtual desktop, ordinary windows maximized and dialogs centered. File dialogs and path fields are confined to the exchange folders. The reference interpreter cannot execute arbitrary external programs; local Git history uses a restricted helper, and in-process notebook plugins remain available. Budgets: calls min(160, 55+30n), seconds min(1800, 540+210n), tokens min(1.5M, 500k+250k*n) for n checkpoints, with larger budgets for the delete episode and the two plugin episodes, whose goals need more steps.
