# Zotero public samples

These example files are copied into the task image as `/app/samples` for exploring the reference: upload them into
its inbox and open them through its normal dialogs (import, attach, RTF Scan).
`manifest.json` lists what each file holds: a two-page PDF with document
metadata, a BibTeX file, an RIS file and a CSL JSON file with a few references
each, and an RTF document with a citation marker for RTF Scan. These are ordinary input examples.
